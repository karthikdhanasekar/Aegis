# AegisAI Architecture

This document describes the high-level architecture of AegisAI.

## Core Components

AegisAI will eventually contain:

1. Web frontend
2. Backend API
3. Target management system
4. Model adapter layer
5. Security test engine
6. Attack orchestration engine
7. Evaluation engine
8. Risk engine
9. Findings system
10. Reporting system
11. Authentication and authorization
12. Audit logging
13. Database layer

## Design Principle

Security controls must not depend solely on the behavior of the AI model.

Application-level authorization, authentication, data isolation, and other security boundaries must be enforced independently of model-generated decisions.
